# Contributing

1. Open an issue describing the correction or enhancement.
2. Keep each change focused and document all affected interfaces.
3. Label every result as analytical, simulated, software-tested, or physically measured.
4. Record tool versions, parameters, random seeds, input provenance, and reproduction steps.
5. Submit a pull request with validation evidence and no confidential or unlicensed third-party material.

By contributing, you agree that your contribution is distributed under the MIT License.
